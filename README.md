# Glz Inbox

A dashboard-first unified communications experience for multiple mail providers.

## Phase 1

- Responsive application shell and sidebar
- Dashboard-first experience
- Light/dark appearance
- Mock recommendations, priority, account, bundle, delivery, and activity data
- PWA manifest foundation

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Target production hostname: `inbox.glztech.com`.
